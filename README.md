# swiper_go

**Start your presentation with a Swipe.**

`swiper_go` is an interactive, web-based presentation deck designed to showcase **ShadowBot (Yingdao) RPA** solutions and automation scenarios across various industries. Built with **Swiper.js**, it delivers a seamless, app-like experience for demonstrating value propositions, case studies, and technical prowess.

## Features

*   **Interactive Slides**: Smooth, touch-friendly transitions between slides using Swiper.js.
*   **Rich Media Support**: Integrated support for video demonstrations, local assets, and dynamic layouts.
*   **Offline Ready**: Optimized for offline presentations with local asset management.
*   **RPA Focused**: Pre-structured content for ShadowBot RPA scenarios, including manufacturing challenges, solutions, and ROI analysis.

## Quick Start

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/swiper_go.git
    cd swiper_go
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the project**:
    Since this is a static HTML project, you can simply open `index.html` in your browser, or use a local static server:
    ```bash
    npx serve .
    ```

## Project Structure

*   `pages/`: Individual HTML slides for different presentation topics.
*   `assets/`: Local images, fonts, and media files.
*   `js/`: Configuration and initialization scripts.
*   `lib/`: Third-party libraries (Swiper, etc.).
